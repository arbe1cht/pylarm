# ПылБудильник

Нативное Android-приложение на Kotlin: будильники с датой или повтором по дням недели, выбор системной мелодии, мировые часы и отключение после 10 правильно решённых арифметических примеров.

## Запуск

Откройте папку проекта в Android Studio и соберите модуль `app`. Для срабатывания будильников разрешите точные будильники; Android также может запросить разрешение на уведомления.

Время показывается с миллисекундами и позволяет задать их для будильника. Android не гарантирует доставку сигнала с точностью до миллисекунды: фактический запуск зависит от ОС и устройства.
